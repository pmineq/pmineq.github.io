Zencut 개인정보처리방침

시행일: 2026년 10월 8일

Zencut은 사용자가 기기에서 사진과 짧은 영상을 촬영하고, 스토리컷 이미지와 무빙컷 영상을 만들 수 있도록 제공되는 iOS 앱입니다. 본 개인정보처리방침은 Zencut이 처리하는 개인정보와 권한 사용 방식을 설명합니다.

Zencut은 자체 서버, 광고 SDK, 분석 SDK를 사용하지 않습니다. 사진·영상과 피부 보정을 위한 얼굴 분석은 기기 안에서 처리합니다. 업데이트 확인에 사용하는 GitHub Pages에는 IP 주소 등 보안 접속기록이 남습니다. 사진·영상·얼굴 분석 정보는 해당 요청에 포함되지 않습니다.

1. 수집하는 개인정보

앱은 이름, 이메일 주소, 전화번호, 위치정보, 광고 식별자 또는 연락처를 자동으로 수집하지 않습니다. 업데이트 확인 시 호스팅 제공자가 처리하는 접속기록은 아래 4항에서 설명합니다.

앱에서 촬영하거나 불러온 사진·영상 및 입력한 문구는 기기 내에서 처리됩니다.

1.1 피부 보정을 위한 얼굴 정보 처리

처리 항목: 사용자가 피부 보정을 켠 경우, Apple Vision 프레임워크가 기기 안에서 사진 또는 카메라 영상의 얼굴 영역과 얼굴 윤곽·양쪽 눈·입술·코·양쪽 눈썹의 위치 좌표를 일시적으로 분석합니다. 여러 얼굴이 감지되면 가장 큰 얼굴의 위치 정보를 피부 보정에 사용합니다. 피부 보정은 기본적으로 꺼져 있으며 사용자가 켜거나 끌 수 있습니다.

이용 목적: 이 좌표는 피부 영역을 찾아 질감을 부드럽게 하고 눈·입 등 세부 영역을 보존하는 데만 사용합니다. 사람을 식별·인증하거나 얼굴 인식용 템플릿을 만들지 않으며, 광고·추적·프로파일링·모델 학습에 사용하지 않습니다.

저장 및 공유: 얼굴 위치 좌표와 분석 결과는 기기 메모리에서만 일시적으로 처리합니다. 앱은 이를 파일·데이터베이스·로그에 기록하지 않으며, Zencut 운영자, Apple, GitHub 또는 다른 제3자에게 전송하거나 공유하지 않습니다. Apple Vision 분석은 기기 안에서 실행됩니다.

보관 및 삭제: 사진 보정용 분석값은 해당 사진 처리 작업 동안만 사용하며 작업이 끝나면 해제합니다. 실시간 미리보기·무빙컷 보정용 분석값은 처리 중 메모리에 잠시 캐시하고 새 감지 결과로 교체하며, 얼굴 미감지·감지 실패 시 비웁니다. 피부 보정을 끄거나, 처리 미리보기를 중단하거나, 카메라를 전환하거나, 앱이 비활성화되거나, 카메라 입력이 중단되면 캐시를 비웁니다. 무빙컷 한 칸의 녹화가 끝나거나 취소되면 해당 분석 캐시를 비웁니다. 앱 종료 후 유지되는 얼굴 분석 기록은 없습니다.

사진·영상과 분석값의 구분: 사용자가 촬영·저장·공유한 사진이나 영상에는 얼굴 모습이 포함될 수 있지만, 얼굴 위치 좌표나 별도의 분석 기록은 첨부하지 않습니다. 사진·영상의 저장·공유·삭제는 아래 3항, 5항, 6항을 따릅니다.

2. 앱 권한 사용

  • 카메라 권한: 사진과 무빙컷 영상을 촬영하기 위해 사용합니다. 무빙컷에는 오디오 트랙이 없으며 마이크를 사용하지 않습니다. 사진 촬영 및 영상 녹화 상태는 화면에 표시되며 사용자가 이 표시를 끌 수 없습니다.
  • 사진 추가 권한: 사용자가 사진, 스토리컷 또는 무빙컷 영상을 사진 앱에 저장할 때 사용합니다.
  • 사진 선택: 커스텀 프레임과 배경 등록에는 iOS 사진 선택기를 사용하며, 사용자가 선택한 항목만 앱에 전달됩니다.

3. 기기 내 저장 정보

Zencut은 앱 설정값을 기기 내 저장소에 저장할 수 있습니다. 예를 들어 플래시 설정, 저장 옵션, 프레임 표시 옵션과 같은 앱 사용 설정이 이에 해당합니다.

사용자가 직접 추가한 커스텀 프레임 이미지는 앱의 로컬 저장 공간에 저장되며, 사용자가 앱에서 삭제할 수 있습니다.

4. 업데이트 확인을 위한 네트워크 요청

Zencut은 필수 업데이트 여부를 확인하기 위해 앱 실행 시와 앱이 다시 활성화될 때 GitHub Pages에 게시된 버전 정보 파일을 요청합니다. 이 요청에는 사진·영상·문구·얼굴 분석 정보, 이름, 이메일 주소 또는 광고 식별자를 넣지 않습니다.

GitHub Pages는 보안 목적으로 방문자의 IP 주소를 기록하고 보관합니다. 요청 시각, 사용자 에이전트 등 일반적인 접속 정보도 호스팅 제공자의 정책에 따라 처리될 수 있습니다. 이는 서비스 제공·보안 및 안정성 유지와 관련된 처리이며, Zencut은 이를 광고 추적이나 이용자 행동 분석에 사용하지 않습니다. 해당 정보의 처리는 GitHub 개인정보처리방침의 적용을 받습니다.

5. 제3자 제공 및 공유

Zencut은 개인정보를 판매하거나 광고 추적 목적으로 공유하지 않습니다. 업데이트 확인 및 지원·개인정보 안내 페이지 제공에 GitHub Pages를 사용하며, 접속기록 처리는 4항과 GitHub의 정책을 따릅니다. 사용자가 직접 공유 기능을 선택하면 선택한 사진·영상이 iOS 공유 시트를 통해 다른 앱에 전달될 수 있으며, 이후 처리는 해당 서비스의 정책을 따릅니다.

6. 데이터 보관 및 삭제

앱 설정, 커스텀 프레임 및 촬영·편집에 사용하는 로컬 데이터는 기기 안에서 처리·보관됩니다. 커스텀 프레임은 앱에서 삭제할 수 있고, 촬영 중인 컷은 초기화할 수 있습니다. 앱을 삭제하면 앱의 로컬 데이터가 삭제됩니다. 사진 앱에 별도로 저장한 사진·영상은 앱 삭제와 관계없이 남으므로 사진 앱에서 직접 삭제할 수 있습니다.

얼굴 위치 좌표와 분석 결과의 보관 및 삭제는 1.1항에 명시되어 있으며, 저장된 사진·영상과 별도로 보관되는 얼굴 분석 데이터는 없습니다.

GitHub가 접속 로그를 보관하거나 삭제하는 기준은 GitHub의 정책을 따릅니다.

7. 아동의 개인정보

Zencut은 아동으로부터 개인정보를 의도적으로 수집하지 않습니다.

8. 변경 사항

본 개인정보처리방침은 앱 기능 또는 법적 요구사항 변경에 따라 수정될 수 있습니다. 변경 시 이 페이지의 시행일을 갱신합니다.

9. 문의

개인정보처리방침 관련 문의는 Zencut 지원 페이지를 통해 접수할 수 있습니다.

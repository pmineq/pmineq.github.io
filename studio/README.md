# ZENCO Studio main page

Studio main page source. The separately maintained Zencut detail page at `/apps/zencut/`, the existing `/zencut/` routes, and other products are not part of this build and must be preserved during deployment.

Run `npm install`, `npm run dev`, and `npm run build`. Overlay the resulting `dist/` files onto the existing GitHub Pages site without deleting other routes.

Set the studio accent using `--accent` in `src/style.css`. Each app can define its own accent on its own page.

The Zencut hover image comes from its official Korean App Store listing (iTunes ID 6816699757).
